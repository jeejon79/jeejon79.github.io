귀여운 환수와 완성하는 그림 이야기

그림 조각을 연결하며 일반 퍼즐, 일일 퍼즐과 마스터 도전을 즐겨 보세요. 이 페이지에서 게임 이용, 저장 데이터와 광고 관련 도움을 받을 수 있습니다.

문의할 때 알려 주세요

앱 버전, 기기 모델, 문제가 발생한 화면과 재현 순서를 문의 이메일로 보내 주세요. 비밀번호, 인증 토큰이나 불필요한 개인정보는 보내지 마세요.

진행도 저장과 복구

별도 회원가입이나 로그인 입력 없이 진행도를 기기에 저장하고, 연결 가능할 때 익명 식별자로 서버와 동기화합니다. 다른 기기로의 계정 이전 기능은 없습니다. 앱 삭제·재설치만으로 서버 데이터 삭제나 진행도 초기화가 보장되지 않습니다.

서버 데이터 삭제 요청

서버의 익명 저장 데이터 삭제를 원하면 이메일로 문의해 주세요. 해당 저장 데이터와 요청자의 관계를 확인하는 데 필요한 최소한의 정보를 안내합니다. 인증 토큰은 보내지 마세요.

광고와 힌트

보상형 광고는 직접 선택해 시청하며, 광고 SDK가 보상 조건 충족을 확인하면 한 번 지급합니다. 보상 조건을 충족하지 않은 취소·오류·광고 없음에는 보상이 없습니다. 일반 전면 광고는 완료한 퍼즐 3판마다 결과에서 다음 화면으로 이동할 때 표시될 수 있으며 대기 시간 제한이 적용됩니다. 광고가 준비되지 않거나 실패하면 진행을 막지 않습니다. 현재 현금 결제 상품은 없으며, 코인이나 보상형 광고로 힌트를 얻을 수 있습니다.
